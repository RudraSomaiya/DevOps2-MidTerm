# Titanic Data Dashboard - Rudra Somaiya
 
## Mid-Term Assessment — Static Data Dashboard Deployment
 
### Project Overview
A static web dashboard built using HTML, CSS, and JavaScript that
visualises the Titanic passenger dataset. Deployed on AWS S3.
 
### Dataset
- Source: Data Science Dojo
- URL: https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv
- Records: 891 passengers, 12 feature
